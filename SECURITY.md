# Security Policy

## Supported Versions

This project is currently under development.

| Version | Supported |
| ------- | --------- |
| Current | Yes |

## Reporting a Vulnerability

If you discover a security issue in this project, please report it privately to the repository owner.

Please do not publicly share security issues or sensitive student information.

Include a description of the issue and steps to reproduce it, if possible.

The issue will be reviewed, and an update will be provided when possible.
